---
name: Vigil visual direction
description: The approved visual language for future Vigil mobile work.
---

Preserve the current Vigil visual direction: red action accents, soft neutral cards, rounded controls, concise encouragement, a calm information hierarchy focused on the user’s remaining money, and a minimal launch screen with only the app icon, wordmark, and subtitle on plain red.

**Why:** The user explicitly confirmed this visual build was “perfect,” so future changes should extend it rather than redesigning the product.

**How to apply:** Match new onboarding, subscription, reporting, administration, and launch screens to the existing spacing, typography, card radii, red primary actions, and plain-language tone. Keep the launch screen free of frames, panels, footer copy, or decorative accents; let the prominent app icon lead the smaller wordmark and subtitle. Onboarding should name concrete money pressures, show a visible personalized-plan preparation state before any offer, and make transaction confirmations refer to what was actually entered.
